# HOTEL — Full-Stack Online Store

## Project Overview

HOTEL is a full-stack web application that demonstrates how a static frontend communicates with a backend API and stores persistent data in MongoDB Atlas.

**Architecture:** Static Frontend → `fetch()` → Express API → MongoDB Atlas

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js and Express.js
- **Database:** MongoDB Atlas
- **Database Access:** MongoDB Node.js Driver
- **Version Control:** Git and GitHub
